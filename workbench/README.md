# MEB · DSH 表格工作台

MEB 的可发布 npm 插件包：`meb-workbench`。包内的 `dsh.bundle.patch` 将服务端 bundle 插入 DSH profile，`dsh.client` 注册工作台和左侧入口。

## 安装

默认 DSH 不带插件市场。打开 DSH Desktop 的「添加插件」，输入 `meb-workbench`、GitHub 插件目录地址或本地 `workbench` 目录，确认来源和依赖后安装。手动安装使用 DSH Desktop 随附的命令运行时：

```sh
dsh plugin --profile desktop add meb-workbench
```

普通 npm CLI 不负责 `desktop` profile。安装完成后，左侧点击「MEB 工作台」。

Plugin Market 是可选插件。没有安装 Market 时，直接使用「添加插件」入口。

GitHub 子目录安装使用 `github:baiye1997/MEB#main&path:workbench`。Windows 遇到 `&path:` 子目录解析问题时，改用 npm 包或本地目录。

## 开发

```sh
cd workbench
npm ci
npm run verify
```

需要 DWG 解析时运行 `npm run setup:cad`。发布包不携带本地 `.venv`；npm 安装版可用 `MEB_PYTHON` 指定能导入 `ezdxf` 的 Python，系统还需 `dwg2dxf`。

首版试用：2026-09-21。点击项目进入概览，再进入表格工作台；3D 不参与录入前置条件。

## 运行

已创建专用 profile `~/.dsh/profiles/meb-workbench`，不改变已有 web profile。当前进程在 3081 端口。

```sh
cd workbench
npm ci
npm run setup:cad
npm run build
dsh --profile meb-workbench --port 3081
```

在 DSH 左侧点击「MEB 工作台」。若提示未认证，使用 DSH 本次启动提供的登录链接，不要共享含 token 的地址。
DWG 导入还需要本机可执行的 `dwg2dxf`（LibreDWG）和 `uv`；`setup:cad` 会在本目录安装独立的 Python/ezdxf 环境，不写入项目数据。

在项目「模型配置」可一次选择至多 8 张 DWG（每张不超过 25 MB），逐张核对图纸单位和候选轮廓，每张图都需重新确认标段/分组，再选择追加到当前模型或建立新模型；跳过某张图不会改变当前导入方式。候选可按图层、编号和尺寸查找；图纸局部位置与项目内拟放置位置分别预览，明显套叠的内外轮廓会阻止重复采用。每张图最多列出排序前 200 个候选，超出时明确提示；扫描超过 50 万图元时提示可能漏检。不同图纸通常应手动核对放置 X/Y；只有确定共用 CAD 坐标系时才选「沿用同一 CAD 坐标」。最后逐栋填写楼栋号、名称、楼层数和层高，点击「生成模型」及页面「保存更改」。每个项目模型最多 30 栋，可继续分批追加图纸，并在模型中按标段筛选；同一楼号可在不同标段重复，收方和签证变更定位都必须有足够的标段/楼栋信息才会匹配。筛选后视角会居中当前楼栋，且不把项目场地边界误画成标段边界。已有 CAD 模型追加时会保留原轮廓、场地边界与中庭。二维 DWG 通常无法可靠提供楼层高度、楼栋身份或全部三维构件，因此这里生成的是需人工核对的可编辑建筑体量，不是自动生成施工级 BIM，也未建立标段与合同/台账之间的业务关联。图纸原文件只读解析并在解析结束时清理临时副本，项目仅保存选中的轮廓坐标与来源文件名、校验值。

日常识图可先筛选候选，点「查看 DWG 局部线条」并放大核对红色候选轮廓与周围图线，再决定是否勾选。局部图由 DWG 转换生成，不能代替完整原图；天正代理对象和绑定图仍可能缺失。

收方和签证变更行可右键「定位模型」：记录中的部位须唯一匹配模型楼栋，填写有效楼层时只高亮该层，否则高亮整栋。收方为蓝色，签证为橙色；多标段模型会切到目标标段。含糊、跨多栋或跨多层的部位不会自动定位。模型内的记录列表可反查原台账行。产值、合同和材料价格没有可靠的楼栋部位字段，不提供定位操作。

日常识图从模型页筛选候选后点「交给 DSH 初筛」：工作台把本张图的候选摘要与原始 DWG 放入项目专属 DSH 会话草稿，用户核对后发送。文件经 DSH 的附件接口保存在会话中；项目模型只保存用户采用的轮廓坐标与来源，不把原始 DWG 写入项目附件库。摘要中的 `decomposedEntityIndex` 是 DXF 块展开后的遍历序号，**不是** DWG handle。解析器会提供图层里的图纸标题片段；若同一绑定图含多层平面，只关联同页图层的附近文字，防止地下室标注被贴到一层轮廓。无同页依据时不显示这类文字。即使有同页文字，也只是空间线索，不证明楼栋身份。如果 DSH 无法直接读取原图，仅可引用这些具体解析标注给出待人工核对的初筛候选；没有对应标注时须返回空候选。DSH 回复须带图纸 SHA-256、候选编号和证据来源；工作台区分原图核对与解析线索。两者均不自动采用，用户还须对照原图逐个勾选、确认标段与坐标。此路径使用 DSH 会话，不调用 Codex。绑定图、天正代理对象及跨图配准仍可能无法可靠解析，不能自动认定楼栋、层高或生成施工级 BIM。

日常项目问答也走同一个 DSH 项目会话。提问默认跟随当前工作：有未保存编辑、筛选或勾选时附带当前范围的有界快照；其余情况发送项目定位，由 DSH 按需查询已保存资料。发送前可展开核对范围，改为附带当前记录或仅咨询业务方法。超过单次容量时分批核对，可继续下一批；后续批次沿用首次发送的范围，刷新后需重新开始。DSH 可调用只读 `meb_project_query` 按项目、台账、关键词与页码继续查询已保存数据，或按行 ID 读取；计算记录的选中行还会返回入账时冻结的参数与公式。`meb_calculation_query` 可列出当前项目的计算工具及自定义规则、分页读取已保存计算行，并按行 ID 返回现行公式的有效参数、来源、结果和计算步骤。当前计算结果与历史入账快照分开核对；快照会标明当前编辑是否尚未保存，不能把工具返回的已保存版本和未保存草稿混为一谈。DWG 识图请求只发送图纸与候选，不重复附带台账快照。DSH 提出的台账修改须经字段差异预览和用户确认才进入可撤销编辑区，保存仍由工作台完成。

## 已实现

- 项目新建、搜索与切换；无模型项目直接工作。
- 收方明细台账：直接编辑，文字/数字/日期/选项字段，自定义列、列宽、隐藏列、搜索、升序排序、草稿过滤和保存视图。
- 多行多列粘贴预览与映射；`.xlsx`、`.xls`、`.csv`、`.tsv` 工作表选择与追加导入，不覆盖已有行，导入在 Worker 中解析并限制 20 MB、2 万行、200 列。收方工程量矩阵可按楼层展开，必须先指定楼栋；现场收方单文书可整单归档。两种模式均生成待核对草稿，不擅自补单位、签认或叙述中的工程量；原 Excel 文件不会自动成为附件。
- 报送量、核定量、差额；按单位分别汇总。数量内部使用十进制定点整数，空值不当作零。
- 记录备注、附件副本导入、已有资料关联、解除关联、资料列表；桌面预览在右侧，不遮挡录入。
- 显式保存 / ⌘S，浏览器草稿、15 步修改撤销；宿主版本冲突保护。过期草稿不能静默覆盖新数据。
- XLSX 导出与 JSON 完整备份由宿主写到本目录 exports，界面显示路径。数字列以 Excel 数值导出（超出 15 位精度时保留文本）。
- 备份恢复先在编辑区预览确认，保存才发布；附件字节包含在备份中。
- macOS 可在“备份与设置”配置 WebDAV 自动同步：填写以 `.json` 结尾的 HTTPS 文件地址、用户名和应用密码。密码进入 macOS 钥匙串，本机仍由 DSH 保存；每次保存后尝试上传，打开工作台时检查远端。断网时本机保存照常完成，恢复连接后可在设置页“立即检查”。
- WebDAV 使用完整 JSON 快照和强 ETag 条件写入。双端都改动时停止自动覆盖，设置页可选择保留哪一端；替换前将另一端写入本机 `exports/`。首次在新电脑连接已有远端时，也须在设置页明确选择使用远端。远端不提供强 ETag 时可读取，但不会自动覆盖已有备份。
- 同步包含项目、台账、模型参数与导入的附件副本，不包含“本机引用”的原文件或绝对路径、浏览器里的模型视角、未保存草稿和 DSH 对话。另一台电脑仍须安装同版本工作台，原文件另行复制并重新定位。目前钥匙串凭据接入只在 macOS 可用。
- 项目总览展示项目关键造价信息与模型；模型参数在独立页面生成，造价档案在独立页面维护。

## 数据与接入

数据领域为 `meb_workbench`，调用 DSH `storageDomain`。当前随附 JSON 后端使用宿主配置的存储根；实际路径可在 `~/.dsh/storages/` 下查找 `meb_workbench.json`。只有插件自己的领域会写入。

通信使用 DSH `connection.fetch` 注册 `/api/meb-workbench` 精确 POST 路由，沿用宿主认证。没有占用 `/api` 唯一 RPC 拦截器；本版本自定义 RPC channel 遇到 service owner 注入限制，因此选择文档支持的精确 Fetch 路由。

原始 CAD、既有 web profile、其他领域数据不修改。真实资料仅作只读解析与预览；写入、保存和重载测试使用独立本机 fixture，不写入示例校园业务台账。

## 当前边界

这是第一批可操作版本，不是全部规划已完成。

- 收方台账仍以每行一条记录存储；整单文书可保存正文，但未自动拆分和核验其中各项工程量，也未实现独立收方单下的多条明细分组。
- 多级产值清单只显示带清单编码的本期分部分项合价及来源核对，禁止逐行导入产值台账，以免清单行与分类小计重复计数。它不自动代替完整期次报送金额。
- 尚未实现拖入附件、降序/多条件筛选、字段重命名、项目归档及完整视图管理。
- 自定义选项列支持输入值，尚无独立的选项配置面板。
- 项目模型可配置楼栋、逐层层高，并从多张 DWG 选择轮廓生成可编辑体量；图纸单位、楼栋身份、跨图定位和高度仍须人工核对，不能视为施工级 BIM。
- 本机 Chrome 已验收 Excel 选择、预览、隔离项目追加及重载；附件 PDF/图片的完整选择、预览和下载链路仍需单独验收。
- 浏览器直接下载未观察到下载事件；XLSX 与完整 JSON 备份已改为宿主生成文件并实测。附件下载副本仍需本机进一步验证。
- 单附件上限 10 MB，单次批量附件总量 20 MB，工作台文档超过 45 MB 时拒绝继续嵌入；单文档保存适合个人早期试用，暂不适合多人并发编辑。冲突会拒绝保存并保留输入，尚无自动合并。
- 签证变更、产值、合同现有独立可编辑台账；多级审批、自动汇总产值、付款流水、班组结算与 AI 业务工具尚未实现。

实测证据与限制见 [验收记录](TEST-REPORT.md)。

## 2026-09-21 导航、台账及计算台更新

- 项目点击进入概览，移除独立“项目概览”菜单；工作台内分收方、签证变更、产值、合同、计算记录，各自字段、视图、导入导出互不混用。原有收方字段、行、自定义列和附件保留。
- 外层工作区纵向滚动，长表不再限制内部高度；概览模型底部可达。左侧导航独立保持可见。
- “项目资料”改为附件库。保存独立导入副本，既非硬链接也非符号链接；业务记录按ID关联副本。可按关联业务台账和未关联状态筛选，同一附件可出现在多个分类。
- 计算台加入电缆铜价调差、母线槽铜价调差（估算/确认铜重）、桥架支吊架重量（门架/单杆）；显示参数、结果、步骤和来源，可存入计算记录。公式分析见 [FORMULAS.md](FORMULAS.md)。
- 日期文本支持 YYYY/M/D、YYYY.M.D、YYYY年M月D日，验证真实日期，不再仅检查文本格式。
- 计算台当前会话参数按项目保留；刷新前请将需要的结果存入记录并保存。源Excel仅只读解析，未修改。


## 概览融合与宿主主题（2026-09-21）

概览采用一个模型工作区：单一项目标题、左侧紧凑业务入口、右侧完整模型；去掉沙盘内重复标题和常驻模型资料栏。显示设置按需展开。窄屏将模型放在业务入口上方，保留整体滚动。

界面采用 DSH 的 `--dsw-alias-*` 主题变量，跟随宿主浅色、深色及系统设置。父页观察主题变化并向隔离模型发送当前颜色，模型重绘材质和光影而不重建相机；嵌入模型预览由 build.mjs 从本地源码派生。CAD几何及台账数据未改。

## 项目计算表与来源反查（最新，2026-09-21）

此节替代此前单条计算器的交互和“刷新恢复样例”的说明。每个项目的 calculationSheets 独立持久化，三类表分别存表头参数和多行明细；不自动带入任何项目铜价、长度样例。铜密度/幅度、支架参数是可编辑默认值。

- 电缆规格解析最多3组芯数×截面积；桥架宽×高解析尺寸，100/150/200/300mm预设来自已核对原表；其他型钢重量需要自定义。母线槽显式排规或确认单位铜重，不能仅凭电流型号推断厂家尺寸。
- 表格支持逐格编辑和从Excel粘贴事项、规格、长度（或从对应列开始粘贴）；多行自动续行。每行支持删除及参数覆盖，空覆盖恢复自动值。
- 金额显示/入账2位，重量显示最多3位；输入和来源快照保留精度。
- 入账按钮明确项目名。每次入账保存projectId、sheetId、rowId、规格、参数、公式版本、时间、原表来源、结果、单位与签名。相同版本禁止重复入账；变更后另存版本，不覆盖历史。
- 台账详情可查看不可变参数快照并反查原行。原行删除后说明来源行已不存在，快照仍在。旧版记录保留原备注，明确无结构化来源行，不虚构映射。
- 历史计算记录不显示总金额，避免把不同版本重复累计。当前计算表显示有效行合计。快照记录的结果与单位锁定，XLSX导出附带备注与来源JSON。
- 当前自定义为输入参数/计算口径覆盖，不支持用户任意公式脚本；暂未做整本Excel计算表自动映射导入。

## 计算明细与批量操作（2026-09-21）

- 计算记录行首固定显示「查看明细」「原计算行」。入账快照用中文字段表展示实际输入、单位、代入数值的算式和原表来源，不再展示 JSON。旧版无结构化来源的记录仍保留备注，不虚构原行。
- 计算表行首固定操作按钮，点击明细、计算方式或结果打开右侧明细。可展开所有参与计算的参数和中间结果列，参数可逐格修改；本行覆盖值可在明细恢复来源值。空白代表未填写，不代表恢复。
- 勾选行后批量入账、复制、删除；缺项行不会入账并说明行号，同版本跳过。一次批量修改可整体撤销；入账快照不随删除原行消失。
- 参数明细显示实际取值和来源（本表共用、本行规格、原表预设、本行填写），不使用「自动」占位。母线槽按铜排尺寸估算或厂家确认 kg/m 分开显示字段；支吊架说明宽度建议规则、吊杆数量和公式切换，保留明确的本行覆盖值。
- 三类计算的数值公式未改变；中间过程显示最多 9 位小数用于复核，金额仍为 2 位，重量结果最多 3 位。

## 业务台账重构（2026-09-22，当前）

- 收方默认字段：收方单编号、部位、专业、内容、清单编码、项目名称、数量、单位、四方签章、备注。签证变更默认编号、部位、内容、签证金额、四方签章、备注；每方有独立签字/盖章复选框。
- 合同分项下（总包）、对下分包、对下班组。产值分报业主、报总包额度、报总包项下合同、班组报我方四口径；记录往来方/合同编号、时间、期次、月度/节点、当期/累计、报送/审定、付款比例、应收应付、已收已付和余额。不同口径及累计数不混加。
- 新增直接进入空白行，不打开记录表单；非必要字段可空。附件按钮按需打开侧栏。旧业务字段保留为可展开列，自定义字段原可见性保留；旧记录不自动猜合同/产值分类。
- Excel 区域可从当前单元格直接粘贴，覆盖所选可见区域、自动续行、支持引号/换行/千分位和常见日期；整次粘贴校验失败不写入，可一次撤销。签章文本用「签字」「盖章」「签字+盖章」；可勾选行复制回 Excel，或连表头复制当前视图。文件导入仍经映射预览。
- 项目金额单独保留合同、清标、一/二/三审；合同金额默认取项下合同合计，可人工覆盖。签证变更可选报送/审定汇总、是否加入下浮基数；两级下浮按连续相乘展示算式。应收/应付 = 审定金额 × 付款比例，余额再扣已收/已付；按金额口径填写当期或累计金额。
- 个人材料价格库独立于项目，保存名称、规格、品牌、单位、价格、含税口径、税率、供应商、日期、地区/项目、来源和备注；支持搜索、表格粘贴、复制、Excel导出、批量复制/删除。导入时可识别“规格、型号”；原表若有“调价”“报价”等含数值的金额列而未匹配单价，会阻止直接追加，须手动确认价格口径，或明确作为无价资料导入并保留原表金额说明。每次报价建议新增行保留历史；带入当前项目计算时复制价格及来源快照，不随原价变更。
- 新增数量×单价、圆管保温净体积、矩形风管展开面积，按项目保存输入和结果，支持复制及区域粘贴。几何工具不自动带损耗/定额系数。
- 当前不自动处理预付款扣回、质保金、罚扣、税差或多笔收付款流水；这些合同条款不从比例推断，可先在备注明确并据实填写已收已付。常用算量工具目前在本项目工具页留存，不自动加入历史计算台账。

## 常用核对与导出

- 在收方工程量汇总中按部位、专业、内容筛选；点击分类可反查明细。
- “保存当前视图”保留搜索、排序及业务筛选。计算记录还保留计算分类与起止日期。
