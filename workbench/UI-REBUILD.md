# 工作台 UI 重构 · 2026-09-22

用户否定当前 OA 式界面；保留 Excel / Notion 的低负担逐格录入、项目隔离、原始记录与快照、CAD几何。完整视觉重构尚未实施，以下组件为调研候选，不表示已接入。

## 候选

- shadcn/ui：https://github.com/shadcn-ui/ui，MIT，约124.3k星。定制基础控件体系；不是直接使用 dashboard 模板。
- React Data Grid：https://github.com/Comcast/react-data-grid，约7.7k星。重点验证输入法、键盘编辑、冻结列、复制粘贴、自定义签字盖章单元格、宿主 React 兼容性。
- Radix Themes：https://github.com/radix-ui/themes，MIT，约8.7k星。可替代的完整视觉组件体系。
- Glide Data Grid：https://github.com/glideapps/glide-data-grid，MIT，约5.3k星。Canvas表格性能强，但签章控件、中文输入与可访问性需做适配验证。

星数取本次GitHub页面，随时间变化。首选 shadcn 定制控件与专业数据表格分工，不以星数替代本地兼容性验收。不得把宿主已有React重复打包。

## 三种布局预览

统一白灰、浅蓝交互色、紧凑表格与窄侧栏。A：表格与右侧检查面板并排；B：全宽表格与下方检查面板；C：单行下方展开。预览含示例数据和生图误差，不作公式依据。最终按用户选定布局实施全局导航、所有工作区、控件、状态、空态与深浅色。

## 本次明确修复

- 收方不生成任何汇总。空白或缺少分类口径的产值行不生成无意义汇总；已有累计快照不相加。
- 已收和未收隐藏为默认字段，保留数据与字段开关；只迁移一次，后续尊重用户设置。
- 业务表、计算表、常用算量工具添加行置于各自操作工具栏首位。
- 计算台明细从遮罩改为并排检查面板，点击原行可收起，支持上下行；窄屏上下排列。
- 计算路径改为短步骤，参数可展开，算式可展开数字语义。
- 引用提供本机目录浏览；只记录路径元数据，不复制文件。重启DSH加载新增服务端接口，客户端热更新不能替代服务端更新。

## A 方案本地实施（2026-09-22）

用户选择 A。工作台、计算表、计算记录及常用工具接入 React Data Grid 7.0.0-beta.47，兼容宿主 React 18/19；计算明细接入 Radix Tabs 1.1.21。没有安装 shadcn CLI 或替换为整套模板。统一窄侧栏、紧凑操作栏、浅蓝强调色、深浅主题、右侧非遮罩检查面板；窄容器上下排列。

现有单元格编辑器与业务校验保留。为了确保 Tab 不跳过横向屏幕外字段、Enter 和新增长表能定位，当前关闭网格虚拟化，提供编辑器 Tab/Shift+Tab 导航；尚未进行万行数据性能验收。更多表格性能优化应在不破坏连续录入的前提下另行验证。

构建和 24 项测试通过；隔离浏览器验收见 TEST-REPORT.md。等待用户实际使用后的视觉与流程认可，未提交或推送。
