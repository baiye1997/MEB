# MEB · 工程造价工作室

## 2026-09-22 大整改方向

模式 Operate。针对个人安装造价工作，保留可编辑台账、Excel 粘贴、右键、撤销、业务签认、来源快照和本地保存。用户明确要求替换此前克制但难用的界面结构。本文件替代旧的累计视觉补丁说明。

## 页面结构

- 左侧是项目目录：项目切换、主要工作区、随工作区展开的台账或计算工具、DSH 项目助手。上下文导航替代台账横向页签和计算工具下拉，主区不重复导航。
- 中央为独立工作纸面：项目上下文、当前台账/工具标题、操作区、表格。未保存状态与保存动作持续可见。
- 右侧是业务单据：先阅读，再按需编辑。收方、变更、产值、合同、材料根据本身字段组织，数量/金额独立对齐，签认状态成组显示。计算过程、入账来源保留。
- 项目看板采用可比较的项目目录行，显示造价阶段、真实金额和业务记录数量，不再装饰性封面卡片。

## 视觉系统

深墨蓝项目目录、浅灰工作底板、白色/宿主深色工作纸面。蓝色专用于活动导航、主动作和选中状态。系统中文字体，正文14px、操作13px、辅助12px，数值用等宽数字。分组依靠位置与留白，避免逐字段大文本框。按宿主明暗适配，不创建第二套主题开关。

Rare UI Bounce Sidebar 与 Folder 保留许可与组件；Radix选择、页签及DayPicker保留。结构在work-navigation.jsx、ledger-document.jsx、project-board.jsx中实现。studio.css拥有新页面结构；原CSS仍暂时承担已有弹层和旧功能控件，后续清理必须逐页验证，不能盲删。

## 边界和验收

不修改用户正式数据，不推送。模型是CAD体量参考，未打通可配置生成。入账为保存前可撤销操作。金额不能跨口径随意相加。浏览器验收遇到连接故障时必须明确标记未完成，不能将构建或模型测试代替布局验收。
